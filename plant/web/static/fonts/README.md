# Dashboard fonts

Self-hosted so the kiosk Pi renders the dashboard the same way without internet.
Latin subsets as served by Google Fonts; all three are under the SIL Open Font
License 1.1 (see the `OFL-*.txt` files next to them).

| File | Family | Weights |
|------|--------|---------|
| `inter-latin-var.woff2` | Inter (variable) | 100–900 |
| `space-grotesk-latin-var.woff2` | Space Grotesk (variable) | 300–700 |
| `dm-mono-latin-400.woff2` | DM Mono | 400 |
| `dm-mono-latin-500.woff2` | DM Mono | 500 |
